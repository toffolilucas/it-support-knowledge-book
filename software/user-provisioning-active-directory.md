<h1>Procedimento de Suporte: Criação e provisionamento de novo usuário em ambiente corporativo</h1><br><p>📌 <strong>Descrição do Problema</strong></p><p>Abertura de chamado pela equipe de Recursos Humanos para o provisionamento de credenciais, caixa de e-mail e permissões de rede para um novo colaborador (processo de Onboarding de TI).</p><br><p>💻 <strong>Ambiente</strong></p><p>Dispositivo: Servidor de Domínio / Active Directory (AD) / Microsoft 365 Admin Center</p><p>Contexto: Gestão de Identidades e Acessos (IAM) / Suporte Corporativo</p><br><p>🔍 <strong>Diagnóstico e Checagem de Requisitos</strong></p><p>Validação da Solicitação: Verificação das informações fornecidas pelo RH (nome completo, cargo, departamento, gestor responsável e data de início). Identificação do modelo de perfil (User Template) a ser espelhado para atribuição correta de pastas de rede e grupos de segurança.</p><br><p>✅ <strong>Solução Aplicada</strong></p><p>1. Criada a conta de usuário no Active Directory/Microsoft 365 seguindo a padronização de login da empresa (ex: <em>nome.sobrenome@empresa.com</em>).<br>2. Definida uma senha temporária com exigência de alteração no primeiro logon.<br>3. Vinculadas as licenças de software necessárias e adicionado o usuário aos Grupos de Segurança (Security Groups) e listas de distribuição do setor.<br>4. Configurado o perfil de acesso às pastas compartilhadas do servidor de arquivos conforme a matriz de acessos aprovada.</p>
